<h1 align="center">Tyrs Hand</h1>

<p align="center">让 Codex 在桌面、移动端和 Discord 之间保持同步。</p>

Tyrs Hand 是一套服务端托管的 Codex 方案：把 Codex 放在自己的机器上运行，由服务端保存会话状态和多端同步能力。你可以继续使用官方桌面端，也可以在手机或 Discord 中接着同一段工作；桌面机器在线时，还能从移动端访问桌面浏览器。

## 你可以用它做什么

### 一套会话，多端接力

- **官方桌面端**：连接官方 Codex Desktop，保留熟悉的线程、Turn、工具调用和交互式提问体验。
- **移动端**：仿官方移动端的项目、会话和消息界面，支持查看历史、继续对话、发送附件以及处理需要用户回答的问题。
- **Discord**：把会话状态和消息同步到 Discord，在不打开桌面的情况下查看进度、发起任务或继续讨论。
- **服务端托管**：会话在服务端持续运行，客户端短暂离线不会丢失上下文；重新打开任一端即可继续。

### 桌面浏览器也能被远程使用

桌面机器在线时，Codex 可以使用该机器上的浏览器完成网页访问、文件交换和浏览器自动化。移动端或 Discord 发起的任务仍然使用桌面浏览器的登录状态和工作环境，不需要把浏览器账号搬到服务端。

### 移动端 SSH 直连

移动端支持直接配置 SSH 连接到自己的机器：选择项目目录、查看项目状态、打开会话并继续工作。SSH 私钥保存在移动端的本地安全存储中，适合个人机器、家庭服务器或开发机。

### 设备与定时任务管理

- 管理多台设备、SSH 主机指纹和项目目录。
- 查看设备在线状态，以及当前设备可用的项目和会话。
- 通过只读授权查看定时任务、运行状态、下次运行时间和历史结果。
- 在任务详情中查看完整指令、日程规则和成功/失败运行记录。

## 适合的使用方式

Tyrs Hand 适合希望把 Codex 放在自己的开发机或服务器上，同时又需要多端访问的人：

- 在桌面端开始复杂开发任务，离开电脑后用手机查看进度。
- 在 Discord 中接收任务结果或继续追问，再回到桌面端处理细节。
- 让定时任务在固定设备上运行，并从手机查看运行记录。
- 使用桌面浏览器的既有登录状态完成需要网页操作的任务。

## 开始使用

完整安装步骤见[最小安装指引](docs/deployment/minimal-installation.md)。整体流程如下：

1. 准备一台长期在线的 Control 服务和一台运行 Codex 的宿主机器。
2. 在宿主机器安装 Worker，并完成一次性设备注册。
3. 在管理后台绑定移动端和 Discord。
4. 在官方桌面端或移动端选择项目，开始第一段会话。

Control 使用 HTTPS 对外提供服务；Worker 运行在实际拥有项目文件、Codex 登录态和浏览器登录态的机器上。桌面浏览器能力依赖该机器保持在线。

## 安全提示

- 不要提交 `.env`、密钥、Codex 登录数据、SSH 私钥或本地缓存。
- 为 Worker 使用专用系统用户，并只授予需要访问的项目目录权限。
- 对外暴露 Control 前启用 HTTPS、管理员强密码和网络访问控制。
- 移动端 SSH 连接会校验主机指纹；主机重装或更换密钥后请重新确认指纹。
